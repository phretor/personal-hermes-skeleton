# Challenges

The behavioral and structural failure modes that can derail the [[02 - Mission|Mission]] even when the [[03 - Narratives|cognitive stories]] are healthy. Narratives names the internal stories; this file names the external patterns: how time, energy, and decisions actually flow when the architecture weakens.

Each challenge:

- **What it looks like**: the observable behavior.
- **Fires when**: triggering conditions.
- **Structural fix**: habit, process, or system-level countermeasure (cognitive reframes live in [[03 - Narratives]]).
- **Framework links**: which goals, strategies, habits, and narratives connect.
