# Projects

What I'm working on right now. The Telos slot exists for *visibility*: to spot the gap between what I'm spending time on and what the [[04 - Goals|Goals]] and [[06 - Strategies|Strategies]] commit to.

Source of truth lives in **[[10 - Projects]]**.

## What counts as a project

A project earns a slot in `10 - Projects/` when all three hold:

1. It serves at least one [[04 - Goals|goal]] (or, rarely, a `[[15 - Priorities and Core Values]]` value without a goal: e.g., a family event).
2. It has a defined outcome: a "done" condition, even if soft.
3. It takes more than ~2 weeks of intermittent effort, or spans more than 5–10 actionable steps.

Anything smaller is a task or note, not a project.

## How this file is used

- **Add a project**: create `10 - Projects/<project-name>/<project-name>.md`. Link from [[10 - Projects]].
- **Retire a project**: when shipped or abandoned, move to `ZZ - Archive/` within `10 - Projects/`, or mark on the dashboard.
- **Monthly review**: confirm each active project still serves a current [[04 - Goals|goal]]. Projects that don't serve a goal are leaks.
- **Quarterly review**: purge abandoned projects from the active surface.
